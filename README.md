Design a complete modern SaaS **HR and Payroll Management Platform UI** called **Lumyn Payroll**, built specifically for **small and medium businesses in Kenya (5–500 employees)**. The platform should help companies manage employee records, payroll processing, attendance tracking, leave management, salary advances, statutory compliance, and HR analytics.

Use the following **technology stack**:

Frontend:

* React (Next.js App Router)
* TypeScript
* Tailwind CSS
* shadcn/ui component library
* Recharts for analytics charts

Backend (API-ready design):

* Laravel (PHP) REST API
* JWT authentication
* Role-based access control

Mobile:

* Flutter mobile apps for Employee, Manager, and HR self-service

Integrations:

* M-Pesa salary payments
* KRA iTax
* NSSF
* SHIF
* Biometric attendance devices
* SMS/email notifications

Design a professional **enterprise SaaS dashboard UI** similar to modern platforms like Stripe, Notion, Rippling, and Gusto. The interface should be clean, minimal, data-driven, and responsive.

• Left sidebar navigation
• Top navigation bar
• Main content workspace
• Responsive design

* Add Employee
